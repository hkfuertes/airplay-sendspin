# UI guide for Sendspin Bridge

Applies to `frontend/**`. Keep the current compact speaker/group management dashboard; do not turn it into a landing page.

- **Stack:** Preact, Tailwind CSS v4, Vite. Style components with utilities in `frontend/src/main.jsx`; keep `frontend/src/style.css` for theme tokens and global defaults. Reuse the existing button, card, input and text class constants before adding styles or dependencies.
- **Palette:** dark canvas `#0e1921`, cards `#16262e`, border `#34464d`, ink `#e8f0ef`, muted `#a4b6b8`, mint accent `#a8edcf`. Use the `canvas`, `surface`, `line`, `ink`, `muted` and `accent` Tailwind theme colors for these roles. System sans typography; subtle rounded corners and thin borders.
- **Layout:** one centered column (`max-w-[1040px]`) with a sticky, compact topbar. Keep the brand, suffix input, Reload and Save & restart there; show status messages in a full-width banner immediately below the topbar, sticky with it, never crammed into its buttons. No hero, overview metrics, duplicate save bar or extra page for settings. Preserve the mobile layout and avoid horizontal overflow.
- **Workflow:** speakers show online status, name, exposure and live volume without opening anything; secondary settings go in native `<details>`. Groups show membership at a glance; editing and speaker chips go in their expandable cards. Volume changes immediately; configuration changes wait for Save & restart. Removing a speaker must also remove it from groups and warn that an available device may be rediscovered. Preserve loading, offline, empty and error states.
- **Accessibility:** keep visible field labels (except the header suffix, which has an `aria-label`), native buttons/inputs, keyboard-operable `<details>`, focus rings, status announcements and reduced-motion behavior. Do not rely on color alone for state.
- **Brand:** `frontend/public/favicon.svg` is the single source for both the topbar icon and favicon; keep its four mint bars on the dark rounded square.
- **Check:** run `cd frontend && npm run build`. Verify the real UI at narrow mobile and desktop widths, keyboard navigation, and `/favicon.svg` served by the bridge. Do not expose the configuration API outside the trusted LAN.
